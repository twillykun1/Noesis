# 当前项目简报（可选）

优先更新已有计划、ADR 或任务记录；仅在缺少适合位置且工作确实需要时使用此模板。按需要删减，不为小改动建档。

- 目标与验收：本次要达到什么，如何判断达成。
- 边界与授权：范围、限制、尚需谁决定的事项。
- 当前决定与理由：采用什么，依据与重要代价。
- 重要选择的落点：选择 → 工程约束 → 实现位置 → 验收证据；只记录影响当前交付的关联，复用已有链接。
- 已完成：实际修改或已执行动作。
- 已验证：具体检查、结果及证据位置，绑定代码版本、配置、数据与环境；未验证要明确。这些条件变化后重新判断受影响证据是否仍有效。
- 证据与未知：观察、推断、待确认事项分别标明。
- 重检条件：哪些版本、配置、外部约定或业务限制变化会使当前建议或证据不再成立。
- 下一步：AI 的下一实际动作；下一必要的人类决定（没有则写无）。

发生实质变化时补充：新证据 → 哪项决定/验收改变 → 旧理由为何不再适用。保留最少的必要历史，不复制整段对话或秘密。
